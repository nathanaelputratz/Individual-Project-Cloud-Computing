# Steady

Rencana aplikasi berupa web app daftar tugas kuliah untuk satu pengguna yang diberi nama Steady. Pengguna dapat mencatat tugas, mata kuliah, deadline, dan status, lalu mengubah atau menghapusnya.

Proyek ini direncanakan mengikuti Track A pada Individual Project dimana web app dibangun dengan menggunakan Python/FastAPI yang direncanakan berjalan di EC2 dan menyimpan data pada RDS MySQL. Bagian frontend dibuat dengan menggunakan HTML, CSS, dan JavaScript.
